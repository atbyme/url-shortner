# My Go URL Shortener

A lightweight, minimal URL shortener built completely from scratch using **Go's standard `http` package**. This is a hands-on practice project created to learn the fundamentals of Go backend development, HTTP routing, and link handling without relying on heavy external frameworks.

## Features
* Built strictly using Go's native `net/http` package
* Lightweight, fast, and dependency-free
* Practice-driven architecture for learning backend routing
* Implement automatic unique key generation for short links
* Handle HTTP redirect status codes correctly


## Tech Stack
* **Language:** Go (Golang)
* **Frameworks:** None (Pure Standard HTTP Library)

##  How to Run

Follow these steps to initialize the module and run the project locally.

### 1. Initialize the Go Module
If you haven't created your `go.mod` file yet, initialize it by running:
---> go mod init url-shortener


### 2. Run the Server
Start your URL shortener application directly using:
---> go run .
